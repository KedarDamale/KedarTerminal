# Wallpaper reference

`landscape.png` is the version-controlled clean wallpaper generated using the
built-in imagegen tool on 7 October 2026. It remains a visual reference; the
existing Ptyxis terminal uses a solid color palette and does not display it.

Prompt: Reconstruct the dark navy charcoal mountain lake forest and teal aurora
landscape from the supplied terminal mockup. Remove all text, prompts, menus,
bars, tabs, desktop dock and status indicators. Preserve dark exposure,
mountains across the lower third, forest silhouettes at the bottom, subdued teal
aurora at the upper right, and a quiet dark area at the left. No UI or watermark.
