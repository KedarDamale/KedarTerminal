# Artwork provenance

`landscape.png` is the clean, text-free background generated with the built-in
imagegen tool on 7 October 2026 using the repository's
`Classic KEDAR terminal art banner.png` as the edit reference. Both are tracked
in Git. No fonts are redistributed.

Prompt: Extract/reconstruct only the dark navy charcoal mountain lake forest
and teal aurora landscape. Remove all text, prompts, greeting, menus, bars,
tabs, desktop dock, status indicators and cursor. Fill removed areas naturally.
Preserve restrained very dark exposure, mountains across the lower third,
forest silhouettes at the bottom, subdued teal aurora at the upper right,
and a quiet dark area at the left for terminal commands. No lettering, UI,
border or watermark.

The build command produces reproducible name masks and PNG frames from this
tracked landscape. Frames live in the XDG cache and are deliberately not
version controlled. Font and Pillow versions can affect those derived pixels.
